# Prompt formulas — character lock, image, video, negatives, continuity

`scripts/build_prompts.py` applies these automatically from `project.json`. Use this file to understand, tune, or hand-write prompts.

## 1. Style lock (identical in every image and video prompt)

```
Disney-Pixar 3D animated feature film aesthetic, soft volumetric warm lighting, subsurface scattering on skin and fabric, large expressive eyes with multiple catchlights, stylized but believable proportions, rich material detail, shallow depth of field with creamy bokeh, warm cozy palette of <3–4 named colors>
```
Words that pull away from the look (do not use as positives): anime, Ghibli, cel-shaded, Dreamworks, photorealistic, live action.
**Seedance-forbidden words** (builder rejects them): cinematic, professional, stunning, 8k, studio, perfect.

## 2. Character lock

Per character, fixed fields: `form` (species/build/age/size), `face` (eyes, brows, distinguishing marks), `hair` or surface/material, `outfit` or signature feature, `palette` (named colors). Rules:
- Name colors, don't say "nice colors". One signature trait that survives silhouette (antenna, ribbons, dent).
- Never change a lock field between scenes; if the story needs a change (costume), make a new character id.
- Paste the **same lock string** into every prompt for that character AND attach the approved turnaround as a reference image.

Turnaround sheet prompt (generated by the builder):
```
<style lock>. Character turnaround sheet on a plain soft cream background: front view, 3/4 view, side view and back view of <lock>, plus three close-up expressions (happy, surprised, worried). Full body visible, consistent proportions across all views, no props, no text labels. <image negative>
```

## 3. Setting lock
One sentence per location: light direction, 4–6 fixed props, materials, time of day. Reuse verbatim; it is what keeps a room from rearranging between scenes.

## 4. Image prompt (per scene × ratio)

```
<style lock>.
<composition for ratio>
CHARACTER LOCK — <lock>. (one per character in the scene)
SETTING LOCK — <setting lock>.
SCENE — <shot>. <one-sentence action>.
Characters must match the attached reference image(s) exactly.
<image negative>
```

Composition lines:
- **9:16:** subject in the middle 70%; top 12% and bottom 20% free of key detail (platform UI).
- **16:9:** re-framed for widescreen, use width for environment, key detail inside the central 80%. Never crop a vertical still.

Reference images (`referenceImages`, gpt-image-2 max 5): character turnaround(s) + previous approved still of the same ratio.

## 5. Video prompt — Seedance 2.0 (default)

Structure: `Aesthetic + duration/ratio → Reference use → Subject → Setting → Action (timed) → Camera → Style → Constraints`.
- 100–260 words; ONE primary motion with degree adverbs ("slowly", "slightly").
- References: `@(img1)` the approved still (exact first-frame look), `@(img2)` character sheet, `@(img3)` previous scene still for continuity. Max 3 reference images on Seedance; **no `startFrame` on Seedance**.
- Set `aspectRatio`, `duration`, `resolution` as API fields too — don't rely on the prompt text alone.
- No in-prompt narrator or on-screen text; add VO and captions in post.

## 6. Video prompt — Gemini Omni Flash (only if the tool is present)

Intent over detail: duration + ratio pinned in text, `<image>` placeholder for the approved still, one continuous shot, explicit exclusions ("Don't add text, captions, extra characters or scene cuts"). Best for conversational *edits* of an existing clip ("change the camera to an over-the-shoulder shot") rather than first generation. See `shared/skills/gemini-omni-flash/prompting/guide.md`.

## 7. Negative prompts

Image negative (inline constraint):
```
Not photorealistic, not live-action, not anime, not 2D, not cel-shaded, not flat illustration. No extra fingers, no merged or melted features, no warped props, no extra characters, no on-screen text, no captions, no subtitles, no watermark, no logos.
```
Video negative:
```
No live-action footage, no photorealistic faces, no anime or 2D look, no flat illustration, no extra characters, no extra limbs or fingers, no morphing or melting features, no costume or color changes between frames, no scene cuts, no sudden lighting change, no on-screen text, no captions, no subtitles, no watermark.
```
Arcads' documented `CreateVideoDto` has no separate `negativePrompt` field, so negatives live **inside the prompt text**.

## 8. Continuity lock checklist (run on every still and clip)

| Check | Fail example |
|-------|--------------|
| Character identity | eye color/shape, signature trait missing, proportions changed |
| Outfit & palette | cardigan turns green, ribbon color shifts |
| Setting props | fern moves, curtains change, light direction flips |
| Time of day / light | golden hour becomes noon |
| Screen direction | character exits left, re-enters from left |
| Scale | robot suddenly bigger than a chair |
| Artifacts | extra fingers, melted hands, text/letters appearing |
| Aspect ratio | clip delivered in the wrong ratio |

Fix order when drift appears: (1) regenerate the still with stronger references, (2) shorten the clip, (3) simplify the action, (4) split the scene. Max 2 retries per asset, then ask the user. Seedance credits are charged at create time — don't loop blindly.
