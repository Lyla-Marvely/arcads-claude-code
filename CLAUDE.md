# Arcads-specific session rules

- **PRODUCTION POLICY — ZERO-COST (owner decision, supersedes the Arcads/Gemini plans below):** produce videos ONLY with free, open-source, local tools via `skills/zero-cost-shorts/`. Do NOT call Arcads or any paid/metered API, do NOT enable billing (Gemini or any), do NOT ask for a card, credit purchase or subscription. If a feature cannot be done free, find a free alternative or say it cannot be done; never ask the owner to pay. Characters = official artwork of APPROVED library characters only.
- **API:** Arcads external API (`https://external-api.arcads.ai`).
- **Auth:** HTTP Basic via `ARCADS_BASIC_AUTH` or `ARCADS_API_KEY`. Setup check: `./scripts/check-arcads-env.sh`.
- **Skill:** `.claude/skills/arcads-external-api/SKILL.md` for API calls, prompts, and polling.
- **YouTube thumbnails:** `.claude/skills/generate-youtube-thumbnail/SKILL.md` (uses the Nano Banana 2 image endpoint via Arcads).
- **Image-ad ecosystem (Meta image creatives):** read `shared/skills/image-ad-prompting/OVERVIEW.md` FIRST. Three skills (`chatgpt-image-ad`, `nano-banana-image-ad`, `image-ad-clone`) + a shared 37-template prompt library. The `image-ad-clone` skill asks which backend to validate against at Phase 1, so generic "clone this ad" prompts route correctly. Output is image files; Meta upload is the separate `meta-ad-builder` skill.
- **Character library (all animation / character skills — pixar-animation-video, pixar-style-ad, claymation-ad, gemini-omni-flash, caption-video, thumbnails, image ads):** read `references/character-library/CHARACTER_LIBRARY.md` before using any LYLA-project character. Use ONLY the master sheet from the matching project folder, attach it as a reference image on every image/video call, never create or alter a character design, never treat an unapproved or `proposed` character as official, and never claim a sheet exists until its file is on disk and in `library.json`. Gate paid generation with `./scripts/check-character-library.sh <Project-Folder> --character <Name>` for EVERY character used (exit 0 required; it prints the character lock and reference files; names are not unique across projects, always `<Project>:<Name>`; The-Last-Letter and LYLA-Anime-Universe are one universe; Maya's canonical design has no hair tie/ribbon); for ARSEIN RESEARCH logos use `--brand` (primary/stacked logo is the default, `--logo alternate` for the horizontal one) and never redraw or regenerate a logo (overlay the original file in post).
- **Cost disclosure:** Always present credit totals as **estimates** — Arcads has no billing endpoint. Tell the user to confirm exact pricing in the Arcads platform.
- **Logging:** Log every generation call to `logs/arcads-api.jsonl`.
- **First-time setup:** If `.env` is missing, run `./scripts/setup.sh`. If `MASTER_CONTEXT.md` is missing, copy `MASTER_CONTEXT.template.md` to `MASTER_CONTEXT.md`.
