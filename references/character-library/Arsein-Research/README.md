# Arsein Research — aset visual brand dan karakter

**Status: kosong. Belum ada gambar atau aset di folder ini.** Menunggu unggahan dari pemilik proyek.

Folder ini menyimpan **seluruh aset visual brand ARSEIN RESEARCH**, bukan hanya logo, dengan pencatatan yang dipisah:

| Subfolder | Jenis | Dicatat di `library.json` |
|-----------|-------|---------------------------|
| [characters/](characters/) | master character sheet | `assets` (karakter) |
| [logos/primary/](logos/primary/) | logo utama | `brand_assets`, type `logo_primary` |
| [logos/alternate/](logos/alternate/) | logo alternatif | `brand_assets`, type `logo_alternate` |
| [brand-assets/](brand-assets/) | aset visual pendukung | `brand_assets`, type `supporting` |

Gambar yang diunggah ke folder mana saja di sini (termasuk langsung ke folder ini) akan diperiksa, dipindahkan ke subfolder sesuai jenisnya setelah Anda setuju, lalu didaftarkan. Nama file asli dicatat.

Aturan penting:
- **Jangan membuat aset baru dan jangan mengubah desain asli.** Logo tidak digambar ulang, diwarnai ulang, di-crop dari sheet lain, atau "dirapikan".
- Logo di dalam gambar master character sheet adalah bagian dari sheet itu. Ia **tidak** diambil sebagai file logo terpisah.
- Pada gambar/video hasil generasi, logo **tidak** ditulis ulang oleh model AI (teks logo hampir selalu rusak). Logo asli ditempelkan di post-produksi.
- Hanya aset berstatus `approved` yang resmi.
